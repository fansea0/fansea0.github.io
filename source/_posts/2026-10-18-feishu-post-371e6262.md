## 问题与方案

开发中可能会有图片的相关功能，在本地调试，发现正常展示，但是呢，部署到服务器之后，图片无法展示。

解决办法：

1. 通过F 12窗口找到访问图的请求，提取URL
2. 在浏览器输入访问，看跳转情况
3. 如果访问非跳转图片本身，则应该Nginx配置问题
4. 更改Nginx配置，将路由映射到本地资源路径

![](/images/feishu/HQHeb62eooiwxkx4aAtc8ZTenrg.png)

```Nginx
    location /media/works/ {
        alias /var/lib/pingdou/media/works/;
    }
```





## 思考

Nginx托管的前端项目，对于新资源路径的访问，一定要注意新增Nginx的资源映射配置
